# azimuth-gameid
Adds command line support for launching games in Azimuth

# Installation
1. Get [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases) (x64 dxgi.dll)
2. Copy the **dxgi.dll** next to **azimuth.exe**
3. Download the mod from [Releases](https://github.com/Blackbird88/azimuth-gameid/releases)
4. Copy the **azimuth_gameid.asi** next to **azimuth.exe**

# Usage
Azimuth.exe --gameid=ID (optionally --skip-launcher)

| Game                                   | ID       |
|----------------------------------------|----------|
| Forza Horizon 2                        | 1A96545B |
| Forza Horizon 2 Present Fast & Furious | 5A9771A4 |
| Forza Motorsport 5                     | 7B35D917 |
| Forza Motorsport 6                     | 64F9397E |

# Compatibility
Tested with Azimuth 1.01
